# 晶塔远征（Crystal Tower Expedition）

原创二维放置爬塔网页游戏。以《宝石与爬塔》的核心玩法与交互节奏为参考，采用原创角色、美术、界面与文案。

- 战斗画面：Phaser 3 纵向剖开塔体战场
- 外围界面：React + CSS
- 模拟内核：纯 TypeScript，固定 20Hz 逻辑步长、种子随机、可重放
- 存档：IndexedDB（单一权威状态），支持导入导出与离线收益

## 快速开始

```bash
npm install          # 安装依赖
npm run dev          # 开发模式（默认 http://localhost:5173）
npm run build        # 生产构建（输出到 dist/）
npm run preview      # 预览生产构建
npm run sim          # 运行无头数值模拟，评估推进曲线
npm run test:game    # 无限推进、旧存档和阵容回归验证
```

手机浏览器支持竖屏和横屏。点按战场投放勇者，滑动查看同层战况和其他楼层。

## 联机存档

Go 服务端托管游戏页面，使用 PostgreSQL 保存账号、会话与进度。构建前端并启动服务后，在游戏的「设置 → 云存档」注册或登录。同一账号可在手机和电脑上继续进度。访客存档仍保存在当前浏览器的 IndexedDB 中。

启动命令和环境变量见 [服务端说明](server/README.md)。手机和电脑在同一局域网时，手机浏览器可访问 `http://<电脑的局域网 IP>:8080/`。

## 玩法

- 默认无限模式，楼层持续向上开放，同屏约 4–6 层横向战斗平台，多楼层并行战斗。设置中可选择经典 300 层模式。
- 英雄自动出战、自动上行；点击具体楼层投放普通勇者（受库存、存活上限与生成冷却约束）。
- 每十层一道关口（护卫 + Boss）；无限模式在当前十层全部首通后自动开放下一段。经典模式保留手动解锁。
- 三个主题区域每 300 层循环：苔藓遗迹、熔炉塔区、冰晶高塔；怪物随层数成长，关口 Boss 轮换。
- 24 名英雄（12 名近战、12 名远程）、18 种普通怪物、6 种 Boss。
- 英雄标明近战或远程，可调整召唤顺序，也可一键恢复近战优先。顺序保存在本地和云存档中，影响英雄入场与复活，入口空间不足时等待；近战可以绕过前方远程队友和炮台。
- 勇者培养、英雄招募与升星、六类宝石八槽合成、简化装备、三个主动技能、任务与成就。
- 100 层解锁本地据点、300 层解锁训练竞技场（本地 AI 规则，无伪造在线玩家）。

## 技术要点

- 战斗模拟与渲染分离：逻辑 20Hz，渲染插值，窗口尺寸不影响战斗结果。
- 目标选择按距离与稳定 ID 排序；每个 Tick 先收集行动再统一结算伤害/治疗/死亡/掉落/首通/转移。
- 同一 Tick 多攻击者击杀同一怪物，掉落与击杀统计只计一次。
- 资源使用安全整数，拒绝 NaN/Infinity/负数。
- 存档 schemaVersion + 备份；导入先校验结构、版本与数值范围。
- 旧存档默认接入无限模式，保留原有资源和养成并补齐新增英雄。已完成的历史楼层按规则重建，画面只维护视口附近楼层，避免随爬塔高度增加内存和存档体积。
- 声音为原创程序音效（Web Audio），首次交互后启动，遵守浏览器自动播放限制。

## 存档位置与导入导出

- 存档保存在浏览器 IndexedDB（库名 `crystal-tower-expedition`）。
- 设置面板内可导出带版本号的 JSON 存档、从 JSON 恢复（先校验再替换）。
- 自动保存每 5–10 秒一次；招募/购买/合成/解锁/领取后立即保存。
- 离线收益最多结算 8 小时，为估算值，只产生挂机金币与据点资源，不自动首通/招募/合成。

## 数值说明

初始数值为一套可启动迭代的平衡（见 `src/game/data/economy.ts`），未宣称已平衡。核心公式：

- 普通怪物生命 `round(40 × 1.022^(f-1))`，攻击 `round(4 × 1.018^(f-1))`，防御 `floor((f-1)/12) × 职业系数`
- 英雄攻击 `基础 × 1.035^(L-1) × (1+0.15×(S-1))`，生命 `基础 × 1.030^(L-1) × (1+0.20×(S-1))`
- 单次伤害 `max(1, floor(攻击 × 技能倍率 × 暴击倍率 × max(0.20, 100/(100+防御))))`

怪物在经典 300 层区间、英雄在前 200 级区间使用上述指数成长，之后接续线性成长；金币与费用限制在安全整数范围内，避免高层出现 Infinity。无限模式可将英雄继续升到 200 级以上。

无头模拟（`npm run sim`）会自动玩家推进并输出关键曲线，用于评估“前两分钟成长 / 前五分钟十层解锁 / 前 30 分钟招募与宝石”等里程碑。

## 已知限制（如实声明）

- 英雄和普通勇者使用独立立绘、四帧行走和攻击姿势。怪物与 Boss 使用独立立绘配合程序战斗动画，其他待补美术见 `art/prompts/MISSING_RESOURCES.md`。
- 训练竞技场当前为占位入口，完整对战流程待后续版本完善。
- 未接入 Service Worker 离线缓存（离线收益为 IndexedDB 估算，不代表可断网启动）。
- 音效为程序音效，背景音乐暂未接入（首版允许关闭音乐）。
- 多标签页 Web Locks 保护为简化实现。
